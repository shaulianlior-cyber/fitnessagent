# Running Coach Agent

סוכן אימון אישי בטלגרם. מחליף מערכת ידנית קיימת המבוססת על Google Sheets,
עוזרי AI, דאשבורד והעתקות ידניות.

**גרסת מפרט:** 1.0 · **תאריך:** 2026-08-16 · **בעלים:** ליאור

## מצב נוכחי

שלבים 0–3 הושלמו מקומית. שלב 3 כולל חיבור Claude אופציונלי דרך משתני סביבה,
אך Google Sheets האמיתי נשאר מנותק מכתיבה.

השלד כולל:

- Telegram-compatible HTTP webhook
- לוג גולמי append-only עם מניעת כפילויות לפי `update_id`
- תור SQLite סדרתי ועמיד להפעלה מחדש
- איחוד אלבום Telegram לאירוע אחד לאחר חלון של שתי שניות
- `sheets.js` לקריאה בלבד מנתוני דמה מקומיים
- בדיקת חיים ב־`GET /health`
- ניתוב דטרמיניסטי ל־query / update / extract / chat
- מנוע כללים קשיח שבו טקסט משתמש אינו יכול לעקוף חסימת בטיחות
- מונים ו־`rebuild` דטרמיניסטיים מנתוני הדמה בלבד
- תקרת טוקנים שסופרת את הקלט המלא ושומרת קלט ועוד פלט מרבי לפני יצירת תשובה
- מאמן שמקבל פסק דטרמיניסטי ואינו יכול לשנות hard block
- זיכרון SQLite לשיחה, סשן והעדפות שאושרו, כולל מודעות לפער של 3+ ימים
- חיפוש טקסטואלי מקומי עבור "מה אמרנו על X" ללא קריאת מודל
- חילוץ 1–4 צילומי מסך דרך Claude Haiku עם ולידציה מספרית ותלת־מצב
- שער אישור עמיד: רק `confirm_extraction:<id>` מפעיל כתיבה; "בוצע" רגיל לא
- prompt caching אוטומטי בשיחות ובחילוץ, ותקרת תקציב שנבדקת לפני כל קריאת מודל
- מעבד runtime עם outbox עמיד ושליחת תשובות וכפתורי אישור ל־Telegram; retry
  אינו מפעיל שוב מודל, זיכרון או חילוץ
- runtime של שלב 3 עדיין מול fixture מקומי ומתאם Sheets לקריאה בלבד

## הרצה מקומית

נדרש Node.js 24 ומעלה. אין צורך בהתקנת חבילות. שאילתות מקומיות ובדיקות אינן
דורשות מפתח; לשיחה מודלית נדרש `ANTHROPIC_API_KEY`, ולתמונות Telegram נדרש גם
`TELEGRAM_BOT_TOKEN`. שמות המודלים ניתנים לשינוי דרך `.env.example`.

```powershell
npm test
npm start
```

ה־webhook זמין בכתובת:

```text
POST http://127.0.0.1:3000/telegram/webhook
```

דוגמת בקשה מקומית:

```powershell
$body = '{"update_id":1,"message":{"message_id":1,"from":{"id":123},"chat":{"id":123},"text":"demo"}}'
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:3000/telegram/webhook -ContentType application/json -Body $body
```

נתוני זמן הריצה נשמרים ב־`data/stage3.sqlite` ואינם נכנסים ל־Git.

## גבול Google Sheets

בשלב 3 המקומי, `src/sheets.js` עדיין קורא רק קובץ fixture. הפעולות `write()`
ו־`update()` תמיד זורקות `ReadOnlySheetsError`, גם לאחר callback אישור. זרימת
האישור והכתיבה נבדקת מול adapter מזויף בלבד; אין בקוד פרטי Google, לקוח Google
או הרשאת כתיבה לשיטס האמיתי.
